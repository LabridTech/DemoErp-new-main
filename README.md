# Bin Sultan Fabrics Management System

A comprehensive ERP (Enterprise Resource Planning) solution designed specifically for fabric and textile companies. This system helps fabric business owners manage every aspect of their operations - from tracking fabric inventory (different types, colors, patterns, quantities) and processing sales at the point of sale (POS) to managing customers, suppliers, employees, and financial records.

## Features

- **Point of Sale (POS)**: Complete sales management with fabric-specific features
- **Inventory Management**: Track different fabric types, colors, patterns, and quantities
- **Customer Management**: Maintain customer relationships and purchase history
- **Supplier Management**: Manage fabric suppliers and purchase orders
- **Employee Management**: Track staff, attendance, and payroll
- **Financial Management**: Credit/debit ledger, daily expenses, and financial reporting
- **Reports & Analytics**: Real-time insights into sales performance and fabric stock levels
- **Role-based Access**: Admin and cashier roles with appropriate permissions

## Technology Stack

- **Frontend**: Next.js 15, React 19, TypeScript
- **Styling**: Tailwind CSS, Radix UI components
- **Backend**: Firebase (Firestore, Authentication)
- **Charts**: Recharts for data visualization
- **PDF Generation**: jsPDF for reports and invoices

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Set up Firebase configuration
4. Run the development server: `npm run dev`
5. Open [http://localhost:3000](http://localhost:3000) in your browser

## Business Purpose

Bin Sultan is designed to help fabric business owners make data-driven decisions about which fabrics to stock, pricing strategies, and business growth. It replaces multiple separate systems (inventory management, POS, accounting, customer management) with one integrated platform, making it easier to run and grow a fabric business efficiently while maintaining accurate records of fabric sales, customer orders, supplier relationships, and generating detailed business reports for the textile industry.
